# movie-lists-ui

Frontend for Movie Club: Vue 3 + Vite + TypeScript, Pinia, Vue Router. Mobile-first. Backend lives in [movie-lists-api](https://github.com/soTsimpikakis/movie-lists-api).

## Local dev

Start the API first (see the backend README), then:

```sh
npm install
npm run dev        # http://localhost:5173, /api is proxied to localhost:8000
```

## Common tasks

```sh
npm run test:unit
npm run lint
npm run format
npm run build      # type-check + production build into dist/
```
